# Socius pitch visuals

Prepared 15 October 2026 for California Burrito, AI Automation track.

- Architecture: a flat technical diagram of the current shared local runtime. PNG has a genuine transparent background. Browser control is a next step, not part of the implemented connector path.
- Indian languages: restrained speech tiles representing India's linguistic diversity. This is conceptual artwork, not a claim that all language features have shipped.
- Baymax: original high-resolution Disney character cutout with the lollipop, no banner. Source: https://static.filmvandaag.nl/shows/original/8000/8142.jpg?v=1
- Product and phone views: actual Socius UI from commit 7b74994, using controlled demonstration data. No live model, connected account or real-tailnet acceptance result is implied.

## Final artwork prompt

Mode: built-in image generation, transparent background.

Use case: stylized-concept. A small supporting image for the problem slide of an India-first AI pitch deck. Illustrate linguistic diversity with precisely two overlapping, thin, matte off-white speech-message tiles, one bearing a large black Devanagari “अ”, the other a large black Tamil “அ”. Restrained editorial product illustration, almost flat, very shallow paper-like depth, soft gray edges and extremely subtle diffuse shading. Front view with a small natural overlap. Off-white, neutral gray and black only. Genuinely transparent alpha. No currency symbols, chrome, metallic reflections, shine, glow, scenery, laptop, robot, extra props, labels or other text.

## Flowchart visual brief

Flat white/gray rectangular nodes, dark text, thin gray orthogonal connectors. Laptop and paired phone connect to the same authenticated API, with Tailscale HTTPS on the phone path. The local Socius runtime connects to the policy/approval boundary and reviewed connectors. Models, memory and scoped skills support the runtime. No decorative objects, gradients, reflections or chrome. Exact technical labels, high resolution, transparent PNG.
